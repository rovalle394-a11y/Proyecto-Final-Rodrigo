# Cocina Fácil

Proyecto desarrollado para la materia Interface y experiencia de usuarios en web.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

## Funcionalidades principales

* Navegación intuitiva entre páginas.
* Búsqueda y filtrado de recetas.
* Dashboard personalizado.
* Sistema de favoritos utilizando LocalStorage.
* Modo oscuro.
* Configuraciones de accesibilidad.
* Diseño responsivo para dispositivos móviles, tablet y escritorio.

## Páginas principales

* Inicio
* Recetas
* Categorías
* Menú semanal
* Dashboard
* Receta individual

## Instalación y uso

### Opción 1: GitHub Pages

Acceder al enlace publicado del proyecto:

https://rovalle394-a11y.github.io/Proyecto-Final-Rodrigo/

### Opción 2: Ejecución local

1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web.
3. Navegar entre las diferentes páginas y funcionalidades del proyecto.
